WongEX4U website - static HTML export
======================================
Open index.html in a browser. Pages link to each other:
  index.html, about.html, build-your-brand.html, unicity-business.html,
  free-training.html, stories.html, media.html, impact.html, connect.html
Images are in /images (illustrations - replace with real photos, keeping the same file names).

Notes for the development team:
- Each page is self-contained (CSS + JS inline). Fonts load from Google Fonts (Anton, Inter).
- Forms show confirmation screens only. Connect them to the CRM:
    Unicity interest form          -> Group A: UNICITY_LEAD
    Build Your Brand registration  -> Group B: WONGEX_BRAND_COMMUNITY
- Video buttons open a player placeholder - add MP4 or YouTube/Vimeo embeds.
- Text in [BRACKETS] is placeholder content to replace.
- Social links (#instagram, #tiktok, ...) and the WhatsApp number need real URLs.
